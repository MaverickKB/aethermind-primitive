# Scope

AetherMind OSS v0.1.0 is a universal, harness-free continuity primitive for agent work.

It provides:
- a language-agnostic AEM v1 format spec;
- a Python reference implementation;
- an installed CLI any agent can shell out to;
- validators, fixtures, docs, and release proof scripts.

Actual work writes layers. Inspection commands are diagnostic only.

Out of scope for v0.1.0:
- hosted sync;
- paid/proprietary product layers;
- private identity, salience, or coordination infrastructure;
- harness-specific architecture;
- MCP as the primary adoption path;
- Node wrapper;
- writing continuity artifacts onto customer/remote machines by default.
