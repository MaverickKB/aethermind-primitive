# Privacy

`.aethermind/` is project data. It may contain sensitive context if agents or users write sensitive content into layers.

Before sharing a repository, release artifact, or export, review `.aethermind/` the same way you would review logs, notes, transcripts, or generated reports.

For remote/customer work, use `aethermind remote-note` so continuity is kept locally by default instead of written onto the remote/customer system.
